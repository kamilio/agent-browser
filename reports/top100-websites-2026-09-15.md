# Top-100 native website sweep — September 15, 2026

## Corpus and method

Similarweb’s published **May 2026** worldwide top-100 list is the corpus, not a verified September ranking.
Source: `https://www.similarweb.com/blog/research/market-research/most-visited-websites/`.
The page's May 14 update label and May reporting label are recorded as published,
not reconciled into a claim that full-month traffic was measured by that date.
All listed hostnames were kept, including subdomains and the unusual `bet.br` entry.
Rankings describe traffic, not safety, quality, or a recommendation to use these sites.

Native build: `ce30caa0603f1b953feef6d3bb745924dac2230a`. Four sequential batches; at most four concurrent processes.
**100/100 homepage navigations attempted; 197 observed HTTP requests including redirects; zero retries.**
Public HTTPS roots only. Existing five-redirect, 20-second navigation, 2 MB response and 256 KB extraction limits.
No page scripts, supplied credentials/cookie headers, browser impersonation, CAPTCHA solving, media or account interaction.
403/429/challenge responses were retained, not bypassed. An attempt is not a successful content retrieval.

## Issues to fix next

1. **Recover static content that the loader rejects.** Zoom returned 300,329 decoded bytes of HTML with HTTP 200 but failed at the reader loader. Its saved body allows offline diagnosis without another website request.
2. **Distinguish useful text from shells and missed barriers.** LinkedIn's 184 bytes are a browser-check interstitial missed by the classifier. Pinterest's 98 bytes are a JavaScript notice; VK's 201 bytes and YouTube Music's 155 bytes are browser-compatibility notices. Instagram, TikTok, Twitch, MSN and Roblox return HTTP 200 but no extracted text. Do not treat these as usable content or automatically enable scripts.
3. **Report the actual limiting resource.** Netflix, Globo and HBO Max exceed the 2,000,000-byte decoded-response cap. SharePoint and AliExpress exhaust redirect budgets. These are distinct failures; do not silently increase limits or retry blocked services.
4. **Retain HTTP failure provenance.** CNN returns an empty 403 without Content-Type and ends as a loader `unsupported` failure. It must not be presented as a successful response or as merely an HTML parser problem.
5. **Reduce misleading static fragments.** PayPal's animated counters flatten into digit sequences, Microsoft includes unresolved price placeholders, and Office's landing includes hidden startup configuration. Keep these as observed extraction limitations, not validated prices or rendered values; the reader currently disclaims hidden-content semantics.
6. **Keep raw navigation logs private.** Redirects can contain server-generated query values even without supplied credentials or cookie headers. Shared report URLs redact query strings; original private HTTP logs do not. A future shareable observer export needs redaction rather than rewriting historical evidence.

No production behavior changed during this sweep, and no current full native-test
release is claimed. Original failing captures remain unchanged. The next work is
targeted offline reproduction, fixture tests and fixes, not repeated broad crawls.

## Evidence

Each numbered site directory keeps `INVOCATION.json`, `stdout.jsonl`, `stderr.txt`,
`http-events.jsonl`, `RESULT.json` and checked `HASHES.json`; extracted text is retained when present.
Batch reviews qualify useful public content versus login/consent/script shells.
`BATCH-1.md` through `BATCH-4.md` in that lane contain per-site manual triage;
adult-site extracts were not assessed beyond metadata and no explicit prose is
included in these reviews. Every one of the 197 observed request starts has a
matching request-close and socket-close event.
The corpus does not establish which site is most visited today or complete the broader browser goal.
