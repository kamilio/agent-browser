# Reading infrastructure documentation

The native reader can recover source-rendered documentation without page scripts.
When a stable URL returns a redirect stub, inspect its visible links and choose an
observed destination with research-link-content --target-link. The native click
path preserves source discovery, link validation and document cleanup. A script,
meta refresh or canonical declaration alone is not an instruction to navigate.
Conflicting hints do not replace the explicitly selected visible link.

For navigation-heavy pages, select a known main-content element explicitly. The
Docker multistage article selection removes repeated documentation navigation
without changing the selected source content. A selector may omit surrounding
qualifications; keep the source and selection scope with the result. Automatic
focus defaults are not changed. Long documents can instead use existing bounded
section extraction; do not silently raise output budgets.
